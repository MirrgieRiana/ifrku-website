# キャラクター画像の置き場所

このディレクトリにキャラクター画像を配置してください。
画像は別途入手してください（著作権の都合上、リポジトリには含まれません）。

| ファイル名         | キャラクター | サイズ推奨 |
|--------------------|------------|-----------|
| `zundamon.png`     | ずんだもん  | 200×200 px |

> **注意**: 画像がない場合でも、スピーチバブルの吹き出しは表示されます（アバター部分は 🌿 絵文字で代替されます）。
>
> 新しいキャラクターを追加する場合は `../_plugins/character_block.rb` の `CHARACTERS` ハッシュにエントリを追加し、対応する画像ファイルをこのディレクトリに置いてください。
